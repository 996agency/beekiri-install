# Beekiri install packages

Public **install ZIP** releases for Beekiri CMS under **996agency**.

## Download

**Latest ZIP:** https://github.com/996agency/beekiri-install/releases/latest/download/beekiri-install.zip

Also on `main` (fallback):
https://github.com/996agency/beekiri-install/raw/main/beekiri-install.zip

1. Unzip → open `START_HERE.txt` / `INSTALL.md`
2. Configure `.env`, migrate, start apps
3. Open admin URL → **/install** once (new sites only)

Source development: [996agency/Beekiri](https://github.com/996agency/Beekiri) (private). This repo is **releases / install packages only**.
