# Beekiri CMS: install

**Beekiri is a free, self-hosted CMS** for websites, shops and forms, by 996agency. Free to use, forever, for personal and client sites. See [LICENSE](./LICENSE) and [TRADEMARKS.md](./TRADEMARKS.md).

## Start a new site

With Node.js 20+ and PostgreSQL 14+ installed:

```bash
npx github:996agency/beekiri-install my-site
```

It downloads Beekiri v1.3.3 into `my-site`, installs it and starts it. Open the setup link it prints, enter your database details and create your site.

Options: `--no-start`, `--no-install`, `--help`.

## Or download the ZIP

[beekiri-install.zip (v1.3.3)](https://github.com/996agency/beekiri-install/raw/main/beekiri-install.zip): unzip, then `npm install` and `npm start`, and follow `START_HERE.txt`.

All releases: https://github.com/996agency/beekiri-install/releases

## Updating

Existing sites update from **Settings → Beekiri Core** in the admin.
